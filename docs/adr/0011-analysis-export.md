# 0011 分析报告Markdown导出

2026-10-31，已实现并验证。结构化分析结果可在工作台查看，本批增加本地报告文件，便于人工交付和归档。此能力是新增产品增量，不冒充原设计已经实现的导出契约。

仅SUCCEEDED任务且非VIEWER显示导出入口，点击后必须重新GET现有result端点，由服务端检查当前公司/空间权限、任务归属、状态、TTL/删除标记并记录RESULT_READ。只使用此次成功响应，不直接下载浏览器缓存。复用既有正文读取权限，无新增角色、端点、迁移、模型调用或AI预算写入，不额外记录不实的文件保存审计。

报告包含固定标题、受理/导出时间、任务ID/标题/冻结配置标识、模型报告标题、摘要、关键结论、约束、未知项和每项证据的段落ID/精确引用。空集合有明确描述，不包含输入全文、目的地/供应商响应、操作原因或密钥。所有动态文本放在纯文本代码块中，动态围栏长度超过内容中的所有反引号连续段，防止模型文本变成HTML、图片、链接或Markdown指令；不调用Markdown渲染器或外部服务。

浏览器下载UTF-8 text/markdown，文件名使用固定前缀和过滤后的任务ID，不采用用户标题。对象URL仅为本次操作创建，触发下载后及时释放。下载开始不代表用户实际保存到磁盘；平台TTL只作用于在线数据，已下载副本不受撤权或自动清理控制，入口附近明确说明报告包含原文摘录及该边界。

读取中禁用重复读取/导出。任务、空间、登录主体或组件上下文变化后丢弃迟到响应，清除旧结果；401/403/404/410和网络失败不生成文件。响应完成时再次检查同一上下文和payloadExpiresAt；过期不下载。导出不使用localStorage/sessionStorage/IndexedDB保存正文，读取和导出共用既有七天TTL清除机制。

本批无PDF/Word/CSV、批量下载、输入全文导出、第三方发布、结果再生成、客户端永久缓存或下载副本撤回。浏览器以全本地夹具验证，不读取真实正文来批量产生主库审计；复用未变后端109项证据，主库仅元数据GET对账。
