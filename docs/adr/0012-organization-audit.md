# 0012 公司组织审计查询

2026-11-02，已实现并通过隔离数据库/浏览器验收，随1.0候选交付。治理操作已经写入organization_audit，但原组织页面仅有最近20条摘要数量；本批提供可核对的安全事件查询，不增加管理员的空间权限。

查询收口在OrganizationService现有admin校验，使用只读REPEATABLE_READ事务。安全六列显式SELECT，LEFT JOIN账户只取当前用户名；不读取detail_json，也不把摘要当作完整变更差异。分页以正Long ID字符串倒序，固定SQL片段和绑定参数筛选tenant/operation/resource；不存在游标资源也不查询其归属。既有tenant外键索引包含InnoDB主键，保留现有迁移。

前端沿用framed-sheet与安全审计列表样式，展开后才加载，避免管理表单被长审计列表淹没。已应用条件与编辑草稿分开。公司切换、页面隐藏、组件卸载、拒绝/错误均清除旧记录；AbortController及请求序号保护迟到回填。页面恢复显示时重新读取最新已应用条件。已生效撤权由下一次请求校验，不声称把已读取资料从用户记忆或截图中撤回。

不新增全文审计导出、detail_json查看、公司注册/邀请、跨公司管理、空间正文访问、时间趋势、写入动作或自动模型调用。新增接口是本批产品契约，不将product-directions建议当作既有授权。
